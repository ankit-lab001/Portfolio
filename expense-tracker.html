Project Overview

About The Project

Expense Tracker is a personal finance management application created to make recording and monitoring everyday expenses simple and convenient.

The application allows users to enter their expenses, organize their spending and keep track of their financial activities through an easy-to-use interface.

The project was initially developed as a web application and was later adapted into an Android application using Capacitor.

The main goal of this project was to build a practical application while improving my understanding of front-end development, JavaScript logic, application design and mobile app deployment.

Development Approach

Built Using Vibe Coding

🤖 AI-Assisted Vibe Coding

This project was developed using a Vibe Coding approach.

I designed the project idea, decided the required functionality and worked on the overall development process while using AI tools, including ChatGPT, as a coding assistant.

AI assistance was used for tasks such as generating and improving code, debugging errors, understanding technical concepts, improving the user interface and helping implement different project features.

The development process was iterative: I tested the application, identified problems, made changes and continued improving the project until the desired result was achieved.

Vibe Coding was used as a development aid, while the project direction, testing, decisions and implementation process were actively handled by me.
